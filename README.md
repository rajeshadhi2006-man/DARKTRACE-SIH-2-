## 📌 Executive Summary

**DARKTRACE-X** is an enterprise-grade Cyber Threat Intelligence (CTI) & De-Anonymization platform engineered for national defense reconnaissance, law enforcement cybercrime units, and digital forensics investigators.

By correlating fragmented darknet footprints across underground forums, darknet marketplaces, cryptocurrency escrow ledgers, TLS infrastructure leaks, AI stylometric writeprints, and multi-relational graph topology, **DARKTRACE-X unmasks malicious operators with court-admissible forensic rigor** compliant with **Section 65B of the Indian Evidence Act**.

## 🚀 Quickstart Guide

### 1. Prerequisites
- **Python:** 3.10+ (Python 3.12 recommended)
- **Node.js:** v18+ (for building frontend assets)
- **Modern Browser:** Chrome, Edge, Brave, or Firefox

### 2. Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/rajeshadhi2006-man/DARKTRACE-SIH-2-.git
cd DARKTRACE-SIH-2-

# Install Python backend dependencies
pip install -r requirements.txt
pip install -r darktrace-x/backend/requirements.txt

# (Optional) Build frontend bundle
cd darktrace-x/frontend
npm install
npm run build
cd ../..
```

### 3. Launch Platform (Single Command)

Start the entire intelligence platform:

```bash
python start.py
```

The system will start the FastAPI backend on `http://127.0.0.1:8000` and automatically launch the Command Center in your default browser.

## ⚖️ Statutory Compliance & Ethical Operation

1. **Passive Correlation Only:** De-cloaking is achieved exclusively through passive telemetry analysis (misconfigured server headers, TLS SAN certificate logs, and public blockchain ledgers). No offensive exploits or attacks on Tor nodes are performed.
2. **Section 65B Indian Evidence Act Compliance:** All artifacts are secured with SHA-256 cryptographic hashes and timestamped audit logs for legal admissibility.
3. **Human-in-the-Loop Safeguard:** All AI-driven stylometric and attribution assessments are advisory with transparent confidence percentages; mandatory human supervisor arbitration is enforced prior to case sign-off.
